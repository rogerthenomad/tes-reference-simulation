# TES Reference Simulation

Interactive 3D simulation of the CIVIS Tech Global Trinium Energy System, rebuilt from the reference Blender model.

- Unit: 40-foot container, four hubs, storage wall, water manifolds
- Facility: eight banks of ten hubs, water, power, and operations
- Teardown: hub break-apart and a representative plate stack
- Cutaway, closed, and x-ray shell, wall isolation, explode, and flow paths

Illustrative geometry. Not a fabrication drawing.
